# Orbe Téléphone

Orbe est une agence d'influenceurs TikTok. Ce projet est un site interactif où toute l'agence vit dans un téléphone iPhone.

## Structure

- `index.html` - Page principale avec toute l'application

## Déployer sur Vercel

1. Connecte le repo GitHub à Vercel
2. Vercel déploiera automatiquement

## Développement local

```bash
python -m http.server 3000
```

Puis ouvre `http://localhost:3000` dans ton navigateur.
